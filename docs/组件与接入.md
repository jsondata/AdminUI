# AdminUI 组件与接入指南

适用版本：当前 0.2.0。AdminUI 是免构建的 Vue 3 浏览器组件和后台布局。可以使用封装组件，也可以在同一页面直接使用 Vue、Element Plus 和 Tabler；不需要把已有组件改写为 AdminUI 组件。

## 运行与加载

通过静态服务器访问项目目录（不要直接双击 HTML）：

```sh
python3 -m http.server 8300 --bind 127.0.0.1
```

完整布局的加载顺序：Tabler CSS、Element Plus CSS、AdminUI CSS，随后依次加载 Vue、Element Plus、中文语言包、AdminUI。可参考 `docs/guide/starter.html`；独立组件参考 `docs/guide/components.html`；混合原生组件和本地数据参考 `docs/guide/integration.html`。富文本需要在 AdminUI 前额外加载 UEditor Plus 的 `ueditor.config.js` 和 `ueditor.all.js`。

## 原生组件可直接使用

创建完整应用后，`createApp` 返回 `{ app, workspace, mount }`。`app` 是 Vue 应用，可在 `mount` 前注册自己的组件、插件和指令。页面模板可以混用：

```js
const Projects = {
  setup() {
    const rows = Vue.ref([{ id: 1, name: '设计' }]);
    return { rows };
  },
  template: `<a-panel title="项目">
    <div class="d-flex gap-2 mb-3"><el-button type="primary">新增</el-button></div>
    <el-table :data="rows"><el-table-column prop="name" label="名称" /></el-table>
  </a-panel>`
};
const admin = AdminUI.createApp({
  home: '/projects',
  routes: [{ path: '/projects', title: '项目', component: Projects }],
  menus: [{ path: '/projects', title: '项目' }]
});
// admin.app.component('MyComponent', MyComponent);
admin.mount('#app');
```

`el-table`、`el-dialog` 等由 Element Plus 提供；`d-flex`、`gap-2` 等是 Tabler 的 CSS 类；`ref`、`computed` 等使用全局 `Vue`。AdminUI 样式会对部分 Element Plus 控件设置全局尺寸和颜色，若已有页面需要不同样式，可在自己的 CSS 中覆盖。独立使用时：`Vue.createApp(Page).use(ElementPlus, { locale: ElementPlusLocaleZhCn }).use(AdminUI).mount('#app')`。

## 组件速查

组件注册名为 PascalCase，模板也可使用 kebab-case，如 `ATable` / `<a-table>`。

| 组件 | 属性 | 插槽或事件 |
| --- | --- | --- |
| ALayout | 使用 `createApp` 提供的工作区 | 默认插槽为页面；单独使用需提供工作区上下文 |
| AMenu | `items`、`active`、`collapsed`、`accordion`（默认 true）、`label` | `navigate(path)`、`expand`；兼容 `children` 和 `items` |
| APageHeader | `title`、`description`、`category` | 默认插槽放右侧操作 |
| APanel | `title`、`description` | 默认正文、`actions`、`footer` |
| AStatCard | `label`、`value`、`change`、`hint`、`icon`、`tone` | 默认插槽；tone：blue、teal、purple、orange、red |
| AFilterBar | 无 | 默认字段、`actions`；`search`、`reset` |
| ATable | `rows`、`columns`、`total`、`page`、`pageSize`、`pageSizes`、`pagerCount`、`loading`、`selectable`、`rowKey` | 列 `prop` 对应的具名插槽；`update:page`、`update:pageSize`、`selection-change`、`sort-change` |
| AForm | `model`、`fields`、`rules`、`loading`、`submitText`、`labelWidth`、`tabs` | 字段 key 对应的具名插槽、`actions`；`submit(model)`、`cancel` |
| AEditor | `modelValue`、`options` | `update:modelValue`、`ready(editor)` |
| AEmpty | `title`、`description` | 默认插槽 |
| ACode | `code`、`label` | 代码作为文本显示，提供复制按钮 |
| AIcon | `name`、`size` | 未知 name 回退到 grid；图标默认对辅助技术隐藏 |

### 菜单

```js
menus: [{ title: '管理', icon: 'layers', children: [
  { title: '用户', path: '/users', icon: 'users' },
  { title: '外部文档', href: 'https://example.com', target: '_blank' }
]}]
```

内部叶子路径需要在 routes 中注册。父节点可设置 `spread` 默认展开；`group: true` 用作分组。`AdminUI.findMenuTrail(items, path)` 返回祖先链。

### 表格

```html
<a-table :rows="visibleRows" :columns="columns" :total="total"
  v-model:page="page" v-model:page-size="pageSize" :page-sizes="[10,20,50]"
  row-key="id" selectable @selection-change="selected = $event">
  <template #status="{ row, value, index }"><el-tag>{{ value }}</el-tag></template>
</a-table>
```

`columns` 项支持 `prop`、`label`、`width`、`minWidth`、`align`、`sortable`。调用方传入当前页数据；组件不会对 rows 再分页。`total` 不传时不显示分页，`pageSizes` 非空时显示每页条数选择，`pagerCount` 为 5–21 的奇数，默认 7。服务端排序可设 `sortable: 'custom'` 并监听 `sort-change`。需要复杂表头、固定列或其他 Element Plus 特性时直接用 `<el-table>`；这些并非全部由 `ATable` 封装。

### 表单

`fields` 是字段数组，支持 text、password、textarea、select、number、date、switch、richtext。字段有 `key`、`label`、`type`、`placeholder`、`disabled`、`col`、`maxWidth`、`full`、`tab`、`hint` 等；select 的 `options` 是 `{ label, value }` 数组。`rules` 使用 Element Plus 表单校验格式。`tabs` 为 `{ name, label }[]`；字段用 `tab` 归组。`col` 为 1–12，控制输入区宽度，窄容器自动铺满。

```html
<a-form :model="form" :fields="fields" :rules="rules" @submit="save" @cancel="cancel">
  <template #owner="{ field, model }"><el-input v-model="model[field.key]" /></template>
</a-form>
```

提交时先校验，成功后发出 `submit`；组件不会发送请求。复杂表单可直接使用 Element Plus `el-form`，无需使用字段配置。

### 富文本与上传

`AEditor` 支持 `v-model`，`options` 传给 UEditor Plus。上传需要业务方通过 `options.uploadServiceUpload(type, file, callback)` 接入；未配置时会提示。详情见根目录 README 的富文本章节。图表页和上传页中的数据及进度均为演示，不是服务端接口。

## 工作区

`AdminUI.useWorkspace()` 只能在完整应用页面组件的 `setup` 中调用。`open(path)` 打开已注册路径并返回是否成功；`close(path | paths)` 关闭标签；`closeRange(path, 'left' | 'right' | 'all')` 批量关闭，守卫阻止时返回 false；`refresh()` 重建当前页面实例；`toggleTheme()` 切换深浅主题。

`active`、`opened`、`current`、`tabs`、`collapsed`、`mobileOpen`、`theme` 是 Vue Ref。标签记录在 sessionStorage，主题在 localStorage，建议按应用和用户设置独立 `storageKey`。

可选的 `canAccess(route)` 在创建工作区时同步筛选允许的路由，并移除未注册路由对应的内部菜单及空分组；返回 `true` 才允许访问。首页必须允许访问。此筛选只执行一次，权限变化后需由应用重新创建工作区；外部链接不会被此回调过滤。

```js
const allowed = new Set(['/home', '/users']); // 由业务接口或配置提供
AdminUI.createApp({ home: '/home', routes, menus, canAccess: route => allowed.has(route.path) });
```

该功能仅用于前端界面控制，不能代替后端授权。

Hash 路由支持 `/projects/:id` 这样的单段路径参数和查询参数。`workspace.open('/projects/42?tag=a&tag=b')` 中不同完整地址对应不同标签；`workspace.current.value.params.id` 取得 `42`，`query.tag` 取得数组 `['a', 'b']`。普通查询项为字符串。直接注册的静态路径优先匹配。动态路径不出现在快速搜索中，可通过业务页面提供具体跳转。可运行 `docs/guide/integration.html` 的详情页查看。

可在 `createApp` 配置同步的 `beforeNavigate(to, from)`，返回 `false` 阻止导航、当前标签关闭或浏览器历史跳转；`to` 与 `from` 包含 `path`、`routePath`、`params`、`query`，初始直达时 from 为 null。首页本身作为默认回退页，不调用初始直达守卫；回调不得返回 Promise；如需确认弹窗，应由页面先完成异步确认，再允许下一次导航。该钩子不替代服务端授权。嵌套通配、可选参数和自动重定向目前未实现。

每个打开的标签分别缓存页面，关闭时销毁对应缓存；打开大量标签会增加内存占用。页面应在 `onActivated` / `onDeactivated` 管理定时器和订阅。不要把菜单可见性当作服务端授权。

## 请求与业务协议

`AdminUI.request(url, options)` 基于 fetch，默认同源凭据、15 秒超时、JSON；204 返回 null；`responseType: 'text'` 返回文本；支持调用方 AbortSignal。非 2xx 抛出的 Error 有 `status`。原生 `fetch` 和其他请求库也可直接使用。

可选的 `createRequestClient` 可以按项目集中配置接口地址和业务协议，也支持统一请求、响应和错误钩子。下面的配置只作用于这个客户端，不会改变 `AdminUI.request` 或原生 `fetch`：

```js
const api = AdminUI.createRequestClient({
    baseURL: 'https://api.example.com/v1',
    timeout: 15000,
    response: {
        codeField: 'code',
        successCodes: [0],
        messageField: 'message',
        dataField: 'data',
        unauthorizedCodes: [1001]
    },
    beforeRequest(url, options) {
        // 在这里按业务需要附加请求头。
        return { url, options };
    },
    onUnauthorized(error) {
        console.log('登录状态已失效', error);
    },
    onError(error) {
        console.log('请求失败', error.message);
    }
});
const data = await api('/projects');
```

`baseURL` 为空时使用原地址；绝对地址不会拼接前缀。响应协议只有显式配置 `response` 时才启用，成功后默认返回 `data` 字段；`dataField: null` 返回完整响应。业务失败的错误包含 `code` 和原始 `response`，HTTP 错误包含 `status`。`unauthorizedStatuses` 默认是 `[401]`，可自行配置；无论 HTTP 状态码还是业务码触发失效，都会先调用 `onUnauthorized` 再调用 `onError`，最后继续抛出错误。

不符合业务协议的接口可单次传 `{ rawResponse: true }` 跳过响应码解析；这只跳过协议解析，不会跳过自定义 `transformResponse` 或错误钩子。204 响应和 `responseType: 'text'` 不进行业务码解析。

正式项目的统一配置位于 `config/admin-ui.js`，不依赖演示目录。按顺序加载 `src/admin-ui.js`、`config/admin-ui.js`、`src/admin-request.js` 后，可直接调用 `AdminUI.api('/users')`。配置中的 `request` 管理接口地址、超时、凭据及令牌请求头，`response` 管理状态码、消息和数据字段；字段名及默认成功码、失效码参考 layuiAdmin 配置，并可根据服务端调整。

默认不自动携带令牌，也不自动跳转登录页。需要时配置 `request.tokenName` 和 `request.getToken`，以及 `request.onUnauthorized`；令牌只会发送给配置的接口域名。单次请求可传 `{ skipAuth: true }` 不附加令牌，或者由业务代码自行设置请求头。若需要使用不同的配置或钩子，可调用 `AdminUI.createConfiguredRequest(config, hooks)` 创建独立客户端；`docs/guide/backend.js` 是可删除的本地接线演示。配置文件是公开的前端资源，请勿放入密钥。

要体验 HTTP 服务端分页，可运行可选的本地模拟服务器：

```sh
python3 tools/mock_server.py
# 打开 http://127.0.0.1:8301/docs/guide/integration.html?api=1
```

它只用于本地演示，使用 Python 标准库和内存数据；接口按 page、pageSize、keyword 返回当前页和 total，不是生产服务。默认静态示例仍可使用普通静态服务器运行。

同一服务还提供 `http://127.0.0.1:8301/docs/guide/backend.html`：演示账号 `demo`、密码 `demo`，以及请求头注入、401 处理和二进制文件上传。上传只计数字节，不保存文件。服务只监听本机，固定令牌和账号仅用于展示接线，不能当作真实认证；生产项目必须替换认证、授权、上传存储及安全处理。

钩子可同步或异步；`beforeRequest` 接收拼接 baseURL 前的地址，可返回 `{ url, options }`，省略时使用原参数；`transformResponse` 在业务协议解析之后运行，其返回值作为请求结果；错误钩子之后仍会抛出错误，若钩子本身抛错，则抛出钩子的错误。请求客户端不自动登录或刷新令牌，业务响应格式由项目配置。安全校验和授权由服务端负责。

## 示例与边界

组件中心展示 Element Plus 和 AdminUI 的组合，不代表所有示例都由 AdminUI 封装。地图文件及来源见 `THIRD_PARTY_NOTICES.md`。项目使用 Vue 浏览器模板编译器，严格禁止动态函数编译的 CSP 需要其他编译方案。真实登录、权限、服务端上传和生产接口需由应用实现。
